# Introduction to the Linux Terminal

## Overview

In this section, I learned the basics of interacting with the Linux terminal and executed my first Linux commands.

---

## Commands Learned

### `echo`

Displays text in the terminal.

```bash
echo Hello
echo "Hello Friend!"
```

Example Output:

```
Hello
Hello Friend!
```

---

### `whoami`

Shows the currently logged-in user.

```bash
whoami
```

Example Output:

```
tryhackme
```

---

## Key Concepts

- The Linux terminal is a text-based interface used to interact with the operating system.
- Many Linux servers do not have a graphical user interface (GUI).
- Basic terminal commands are essential for system administration and cybersecurity.

---

## Skills Gained

- Understanding the Linux terminal
- Running basic Linux commands
- Displaying text with `echo`
- Identifying the current user with `whoami`
