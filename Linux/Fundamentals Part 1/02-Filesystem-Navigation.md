# Filesystem Navigation

## Overview

In this section, I learned how to navigate the Linux filesystem and interact with files and directories using basic terminal commands.

---

## Commands Learned

### `pwd`

Displays the current working directory.

```bash
pwd
```

---

### `ls`

Lists files and directories.

```bash
ls
ls Pictures
```

---

### `cd`

Changes the current directory.

```bash
cd Pictures
cd /home/ubuntu/Documents
```

---

### `cat`

Displays the contents of a file.

```bash
cat todo.txt
cat /home/ubuntu/Documents/todo.txt
```

---

## Key Concepts

- Navigate between directories using `cd`.
- View files and folders with `ls`.
- Display file contents using `cat`.
- Find the absolute path with `pwd`.
- Use absolute paths to access files from any location.

---

## Skills Gained

- Navigating the Linux filesystem
- Reading text files
- Understanding absolute and relative paths
- Using common filesystem commands
